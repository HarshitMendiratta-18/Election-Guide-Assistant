**ElectionGuide Pro** is an enterprise-grade, interactive platform designed to revolutionize voter awareness and engagement. Built for high-stakes environments, it leverages Google Cloud's power to provide a seamless, secure, and educational experience for citizens.

---

## 🌟 Key Features

### 1. 🤖 AI-Powered Assistant
A guided, interactive journey ("Path to Democracy") that breaks down complex electoral processes into simple, digestible steps.

### 2. 🗳️ Interactive EVM Simulator
Experience a real-world voting scenario. Our 7-step simulator mimics the exact flow of a polling booth, complete with identity verification, digital queueing, and secure vote casting.

### 3. 🧠 Voter Awareness Quiz
Gamified learning! Test your knowledge on electoral laws and procedures. Perfect for first-time voters.

### 4. 🗺️ Smart Booth Finder
Integrated with **Google Maps API**, users can instantly find their nearest polling station and get real-time directions.

### 5. 📊 Real-time Data Analytics
Beautiful, interactive dashboards powered by **Chart.js** to visualize voter turnout and election trends.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- Google Cloud Service Account (for Vision AI & Storage)
- Firebase Project

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/HarshitMendiratta-18/Election-Guide-Assistant.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your environment variables:
   - Copy `.env.example` to `.env`
   - Add your Google Cloud and Firebase keys.
4. Run the development server:
   ```bash
   npm run dev
   ```
